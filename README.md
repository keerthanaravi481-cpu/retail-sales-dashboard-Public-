# Retail Sales Performance Dashboard

> Power BI dashboard analyzing retail sales, profit, and discount performance, with data cleaning in Python and DAX measures for YoY growth and margin.

## Objective
Turn raw retail transaction data into a decision-ready Power BI dashboard covering
sales, profit, and discount performance.

## Dataset
[Sample Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final) (Kaggle)

## Tools
Python (Pandas), Power BI (DAX), Google Colab

## Process
1. Cleaned ~10K sales records and engineered date/shipping features
2. Modeled the data and wrote DAX measures for YoY growth and profit margin
3. Built a 3-page dashboard: Overview, Product Performance, Customer/Segment
